# Divar Ladder Ads Scraper

This project extracts advertisements that have the "Ladder" tag from the first page of Divar website.

The script uses web scraping techniques with Python to parse HTML and filter promoted ads.

---

## Features
- Fetches data from Divar website
- Parses HTML using BeautifulSoup
- Filters ads containing "نردبان" tag
- Prints clean list of results

---

## Technologies Used
- Python 3
- Requests
- BeautifulSoup4

---
